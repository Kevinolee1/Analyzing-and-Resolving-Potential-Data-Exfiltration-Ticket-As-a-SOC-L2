# Analyzing-and-Resolving-Potential-Data-Exfiltration-Ticket-As-a-SOC-L2
As a SOC Level 2 analyst, reviewed SIEM alerts, endpoint telemetry, network connections, user activity, destination IP/domain reputation, and file access patterns to determine whether the activity represented legitimate business behavior or malicious data transfer.

Sign in to the designated SOC Level 2 analyst account.
![Image alt](https://github.com/Kevinolee1/Analyzing-and-Resolving-Potential-Data-Exfiltration-Ticket-As-a-SOC-L2/blob/513105af12fb60cd665e70fa2a2291f7db1a13aa/Screenshot%202026-08-20%20111757.png)
Select the “Potential Data Exfiltration” ticket to begin the investigation.
![Image alt](https://github.com/Kevinolee1/Analyzing-and-Resolving-Potential-Data-Exfiltration-Ticket-As-a-SOC-L2/blob/fcd2eaa1967135e066ee462944db20ac24fda8d4/Screenshot%202026-08-20%20112124.png)

Scroll down to the Post Reply section and select the most recent message to respond to. In the text box, document the investigation findings, risk assessment, response actions, resolution, and final disposition. Set the Ticket Status to Closed, then select Post Reply to submit the response and close the ticket.
